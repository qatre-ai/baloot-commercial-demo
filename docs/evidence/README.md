# Browser Evidence Index

این پوشه فقط شامل تصاویری است که در محیط واقعی QA و با مرورگر Chrome ثبت شده‌اند. هیچ تصویر ساختگی یا اسکرین‌شات تولیدشده با ابزار تصویری در این مجموعه استفاده نشده است.

## شواهد موجود

| فایل | سناریو | نتیجه |
| --- | --- | --- |
| `registration-step1.png` | شروع فرم ثبت‌نام عمومی | فرم و انتخاب نقش قابل استفاده است |
| `registration-step5.png` | مرحله پایانی فرم قبل از ارسال | مرحله نهایی با داده معتبر قابل مشاهده است |

## مواردی که عمداً به‌عنوان اثبات‌نشده باقی مانده‌اند

این فایل‌ها تا زمان اجرای دستی همان سناریوها در مرورگر تولید نشده‌اند و نباید به‌صورت مصنوعی ایجاد شوند:

- `instructor-dashboard.png`
- `admin-dashboard.png`

همچنین این پوشه به‌تنهایی جایگزین گزارش Network/Console، تست خودکار Playwright/Cypress یا ماتریس کامل responsive نیست. وضعیت این گیت‌ها در `docs/testing/QA_RELEASE_REPORT.md` ثبت شده است.

## منشأ شواهد

- مرورگر: Chrome واقعی روی `http://localhost:3010`
- محیط داده: SQLite ایزوله در `db/qa.db`
- حساب اجرایی ثبت‌نام: کاربر عمومی بدون ورود
- حساب اجرایی مدیریت: `qa.secretary@mab.local`
- حساب اجرایی سطح بالا: `qa.superadmin@mab.local`
- زمان ثبت: ۱۷ اوت ۲۰۲۶
